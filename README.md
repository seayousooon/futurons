# Futurons

**Imaginons et construisons ensemble un monde plus heureux.**

Futurons est un projet de site collaboratif pour partager des **idées**, des **projets**, des **réalisations** et des **procédés existants** qui contribuent à un avenir positif.

## Objectif
Rassembler les initiatives inspirantes, faire circuler les solutions et favoriser l'intelligence collective.

## Site
Ce dépôt contient un site statique prêt pour GitHub Pages.

- `index.html` : page d'accueil.

## Publication sur GitHub Pages
Dans le dépôt GitHub, ouvrir **Settings → Pages**, puis choisir **Deploy from a branch**, la branche **main** et le dossier **/(root)**, puis enregistrer.

Le site sera accessible à l'adresse : https://seayousooon.github.io/futurons/

## Participer
Les contributions et suggestions sont les bienvenues.
